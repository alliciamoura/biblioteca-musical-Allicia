# 🎵 Sistema Musical

## 📋 Sobre o Projeto

Este projeto foi desenvolvido como uma atividade prática de Desenvolvimento Web, com o objetivo de criar a interface de um **Sistema Musical** utilizando HTML e CSS.

O sistema apresenta páginas para acesso, cadastro e gerenciamento de artistas e músicas, com uma interface organizada e de fácil utilização.

## 🎯 Objetivo

Praticar os conhecimentos de HTML e CSS, trabalhando com formulários, tabelas, links, organização de conteúdo e estilização de páginas web.

## 💻 Tecnologias Utilizadas

- **HTML5:** Estruturação das páginas.
- **CSS3:** Estilização, cores, fontes, espaçamentos e layout responsivo.

## 📁 Estrutura do Projeto

O projeto é composto por cinco páginas HTML e um arquivo CSS:

| Arquivo | Descrição |
|---|---|
| `index.html` | Página inicial do sistema. |
| `login.html` | Tela de login. |
| `cadastro_artista.html` | Formulário de cadastro de artistas. |
| `cadastro_musica.html` | Formulário de cadastro de músicas. |
| `listagem_musical.html` | Página de listagem de músicas. |
| `style.css` | Arquivo responsável pela estilização das páginas. |

## ✨ Funcionalidades e Recursos

- Página inicial com opções de navegação.
- Tela de login com campos de usuário e senha.
- Formulário para cadastro de artistas.
- Formulário para cadastro de músicas.
- Campo para seleção de imagens.
- Listagem de músicas em tabela.
- Estilização padronizada entre as páginas.
- Layout responsivo para diferentes tamanhos de tela.

## 📱 Layout

O projeto utiliza uma identidade visual com cores, botões, cards e formulários padronizados, buscando proporcionar uma navegação simples e organizada.

## 📚 Aprendizados

Durante o desenvolvimento desta atividade, foi possível praticar a criação de páginas HTML, a utilização de formulários e tabelas, a navegação entre diferentes páginas e a aplicação de estilos com CSS.

Também foram trabalhados conceitos de organização de arquivos e responsividade.
